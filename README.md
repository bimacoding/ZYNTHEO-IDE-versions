# Zyntheo IDE Versions

Update metadata for Zyntheo IDE auto-updates.

The packaging pipeline in [`bimacoding/ZYNTHEO-IDE-builder`](https://github.com/bimacoding/ZYNTHEO-IDE-builder) writes latest-version files here. Desktop builds read:

`https://raw.githubusercontent.com/bimacoding/ZYNTHEO-IDE-versions/refs/heads/main`

This repository replaces the historical Void `voideditor/versions` endpoint. It is empty until the first Zyntheo release workflow publishes metadata.
